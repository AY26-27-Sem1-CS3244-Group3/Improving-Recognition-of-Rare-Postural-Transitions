Rare transitions in smartphone activity recognition

Improving recognition of rare postural transitions

As expected in our CS3244 proposal, standard models recognise common activities more reliably than the brief transitions between postures. This round tests ways to improve minority-class test performance.

All HAPT windowsSix postural transitions: 518 / 10,929 (4.7%)
12 classes6 common activities + 6 transitions
4.7%of labelled windows are transitions
Macro-F1primary metric for rare-class recognition

Three changes to the training signal

METHOD

Keep temporal context

Join the previous, current, and following feature windows within each participant.

Previous
561 featuresCurrent
561 featuresFollowing
561 features

1,683 features per example. The following window makes this an offline classifier.

Weight rare-class errors

Each training example receives a class-based weight computed within its training fold.

wc ∝ nc−0.5

Weights are normalised to mean 1. No model architecture or model hyperparameter is changed.

Copy rare examples

Randomly oversample transition examples in training folds only.

Test targets: 60 or 100 rows per transition class. Tested as an addition to context + weighting.

Weighting implementation: sample weights for logistic regression (C=0.1), linear SVM (C=0.01), random forest (200 trees), and XGBoost (300 trees; depth 6). The MLP uses weighted cross-entropy (256-128-64 units, Adam 0.001, 20 epochs). An earlier PCA-200 ablation hurt the four non-neural models and was nearly neutral for the MLP, so these results use raw features.

Validation: 3-fold StratifiedGroupKFold, grouped by participant (seed 42). Test results are descriptive; the project test split was examined earlier.
